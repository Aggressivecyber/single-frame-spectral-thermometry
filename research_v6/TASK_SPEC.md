## 1. 阶段 A：固定输入的连续谱来源置换（不训练，必须先执行）

### 输入与冻结

使用 v5 已经看过的 36 个 development 母场景，以及必要的 12 个 oracle 诊断母场景；保留正/负 normal、正/负 weak、blank、连续无噪、量化与含噪版本。只为诊断复用这些样本；任何新候选的独立证明不得来自它们。一个 raw 必须在全部方法中逐字节相同；不得更换 Poisson 随机流后称为同输入。

### 方法矩阵

在同一原始 raw 上得到以下连续谱字段：

- C_true：合成真值，仅 oracle 诊断。
- C_v5：当前 700/905 解调与 warm 拟合所得连续谱。
- C_v3：已冻结 v3 联合求解的 state,beta 提取出的 physics.components(state,beta)[0]；只用 raw 推理，不含真值。不能把 v3 的 continuum_postblur 当成 latent C 再施加一次物体模糊。
- 可选 C_B4：原权重输出的连续谱，仅用于参考，不参与模型选择或物理基线标注。

固定同一个 v5 线性 S,beta 估计器和相同 alpha、W、数值预算，依次置换 C_v5、C_v3，与历史 O0/O1/O2/O3 并列。分别保留 true-beta oracle 和 deployable estimated-beta 结果。不得调整其它变量来适配某一个 C。

### 关键诊断（需真正落地）

1. 比较 T_color、C_700、C_905、可见波段连续谱及完整 raw 投影误差；全部在合法 postblur 语义下评分。
2. 将连续谱误差的 raw 残差写为 r_C = A(C_true-C_est)，按同一固定 W 与 beta 子空间求其投影到 signed 模板解中的等效虚假模板 S_leak，报告模板误差与 S_leak 的配对相关及 RMS。
3. 对二次线性求解器实施分量分解恒等检查：设 G=[A_S,A_beta]，x=(S,beta)，K=GᵀWG+Λ，y=A(C_true)+G x_true+n。则

   `x_hat-x_true = K^-1 GᵀW A(C_true-C_est) + K^-1 GᵀW n - K^-1 Λ x_true`。

   以相同数值求解器分别计算连续谱泄漏、噪声、正则化偏差三项，并在可观测 postblur S 上检查重组成的误差与实际误差一致。若恒等残差较大，先检查尺度、正则、beta、重复 blur、W 是否真的固定，不开展后续优化。
4. 分开记录估计连续谱失败、后续线性求解失败和测量可能不可辨三种情形。不能仅凭 raw weighted RMS≈1 宣称物理正确。

### 阶段 A 决策

- 若 C_v3 与同求解器组合，使含噪正常正负模板 RMSE 明显从 v5 约 64 e 下降、接近 v3 的约 17 e，则确认优先级是连续谱反演；后续继续以 v3 为起点，而非 v5 的硬冻结 700/905 初始化。
- 若 C_v3 已显著改进温度，却仍无法改善模板，则说明需要让 T/a/S/beta 在共同 raw 目标里继续耦合优化；进入阶段 B。
- 若 C_true oracle 在已核验合成输入上异常退化，或误差分解恒等检查失败，立即停止，先排查正向／伴随、参数单位和数据链。不得通过训练补救实现错误。

交付：V6_A_REPORT.md、每例 continuum_source_comparison.jsonl、continuum_leakage_decomposition.jsonl、数值恒等单元测试、错误案例可视化、输入/源码/权重哈希与停止结论。

## 2. 阶段 B：仅在 A 指明有必要时，实现可观测带宽的 variable-projection 联合估计（不训练）

### 数学目标

保留原始完整编码算子、真实 object_blur、Planck band integration 和相机响应。令 theta=(T,log a)，C(theta)=a C(T)；用 s_b=H*S_latent 表示真正需要估计的模糊后有符号模板场。s_b 应限制在 OTF 的允许频率支持 B 内，零频段不被网络伪造。已知 M 在场内为常数，有 H(M_k S)=M_k H(S)，因此模板观测为 R(sum_k P_k M_k s_b)，而不再对 s_b 重复 H。

设 F_C(theta) 为现有连续谱经一次 H 与编码得到的 raw，G_s s_b 为经编码图案和中继传递的模板贡献，G_beta beta 为低维背景。使用单份 raw 目标：

`J(theta,s_b,beta) = 0.5 || W^(1/2) [y - F_C(theta) - G_s s_b - G_beta beta] ||^2 + R_T(theta)+R_s(s_b)+R_beta(beta)`。

内层 s_b,beta 是线性二次问题；外层更新 theta。可使用变量投影／交替下降、Schur complement 或联合阻尼 GN，但不得冻结错误连续谱，也不得把解调后的相同 raw 再作为独立测量相加。

### 实现限制

1. 初始 theta 使用现有 v3 纯物理估计；可将 700/905 解调结果仅用作另一初始化对照。
2. signed 子问题在 B 的有限 Fourier 基（名义上约 1153 个非零采样频点，正确处理复共轭与边界 OTF）求解，或使用等价的带限投影算子。不要对 65,536 维几乎不可观测 latent S 盲目做 Hessian 逆；也不要除以接近零的 OTF。
3. beta 保留现有三系数结构。对观测使用固定正 W，记录 raw 一致性、T/a/S/beta 变化、正则项、步长、接受率及停止原因。
4. 仅进行一个小的验证正则网格（例如 template smoothness 3 档×continuum regularization 2 档），参数必须有明确的物理单位及标准化定义。不把不同求解器的 alpha 直接视为同一个数值尺度。
5. 必须在 16 个旧确定性回归输入上排除严重退化；在已看过的 36 个开发母场景上比较名义含噪正负模板、弱信号、blank、色温及母场景级配对差；全失败、CG 未收敛、有效性异常都入表。
6. 性能报告同时包含推理总耗时与 memory peak。当前 v5 约 26.45 s/帧不支持 10 kHz 声明；本阶段先解决科学正确性，之后才设定速度优化里程碑。

### B 的开发门槛与强制停止

对冻结 v3 基线设置不劣性：名义色温 RMSE 不超过 v3 的 1.05 倍；正常正、负模板 RMSE 分别不超过 v3 对应值的 1.05 倍；幅度投影不得明显趋近零；任何无效／拒绝不得通过从误差分母剔除来美化结果。若达到不劣性，再要求至少一个主要指标出现相对 v3 ≥10% 的配对改善，且其它核心指标不显著退步，才称本轮具有继续价值。弱信号分别和零估计 L2=1 与 null 阈值比较，低于检出能力者允许 abstain 并必须报告覆盖率。

- 通过：冻结无网络候选及完整配置，另外预登记独立确认套件；确认前不做新一轮训练或调参。若需要论文中的轻量网络，只能作为额外、预登记的单一对照。
- 未通过：最多一次针对已定位数学／数值原因的代码修复及复验；若仍无可靠改进，终止在此合成标定下的“继续堆重建模型”路线，保留 v3 为比较基准，转向采集/光谱/编码设计优化或论文负结果。绝不重复 v4.1—v4.6 的微调循环。

交付：V6_B_REPORT.md、bandlimited_operator.py、variable_projection_solver.py、物理正向/伴随数值测试、和 v3 同 raw 配对的各组母场景指标、错误分解、超时/失败记录。

## 3. 研究方向切换（仅在 A/B 不支持算法收益时）

选择固定总光子预算的正向成像设计实验，而不是免费提高信号强度：比较滤波片带宽、700/905相对增益与通道光谱响应、载频/调制度、曝光/量化。在相同总入射与记录电子数约束下，量化小维度 T/loga/S/beta 信息矩阵的条件和 nuisance 消去后的可检测模态。禁止把13个有限模式的 Fisher 结果当全图 CRLB；对不能观测的物体高频明确标记不可恢复。未来实物系统需外部定标和独立光谱/黑体参考。
