# 推荐架构：TV锚定的分组辐射保真展开网络

审阅对象：Aggressivecyber/single-frame-spectral-thermometry，research/hybrid-residual-001，提交 9719bdc19c2b800b7685084709b5c6c403a9b3bb。

这是针对当前六通道联合成像方向的新架构规格，不是已经实现或训练成功的模型。附带脚本仅验证辐射敏感性和一个小型凸优化接口，没有运行已发布权重或相机数据。

## 0. 本轮只解决当前六通道问题

输入仍是一张原始ADC图；重建目标是光学模糊后的六幅滤光通道图，顺序为 [431.5,486,516.5,700,800,905] nm。色温和波段超额发光通过统一的确定性Radiometry读出计算。

不要恢复早期七通道latent T/a/单模板的研究目标；不要把旧负AlO模板门禁作为当前物理发射任务的主验收；不要将六个波段都压到一个低秩化学谱子空间。这里的超额发光不是化学浓度。

推荐名称：TV-Anchored Role-Separated Radiometric Unfolding（可简称 TV-RRU），仅为本项目工作名，不表示它是已有论文或已经验证的新方法。

## 1. 当前实现中应当修改的四个机制

1. LearnedReconstruction从FFT初始化，而不是从表现最好的TV结果开始。
2. data_step只最小化raw加权残差和到CNN proposal的二次距离，没有保留TV项。因此它不是“TV与CNN融合”，而是“CNN和WLS型近端求解”。
3. 当前18→24→24→6三卷积共享先验直接混合六路。近红外通道可以利用辐射相关性，但三个可见波段的独立注入不能依赖共现形态。代码没有结构性的跨可见波段隔离，也没有配对注入损失。
4. 当前已有平均强度损失和热通道log-ratio损失，不能把“再加这两个已有损失”称为新修复。需要更明确的热通道坐标、读出误差监督以及注入响应约束。

主条件记录：TV色温54.59 K；混合三个种子81.79–85.59 K。TV发光RMSE为51.76/63.62/71.06 e；混合种子均值为93.12/100.71/109.04 e。以上均来自仓库报告，不是本次复跑。

## 2. 总体前向结构

raw_DN
  -> 原有黑电平/电子转换/共享强度归一化
  -> 固定当前估计W、噪声尺度、光学支持
  -> 收敛的WTV基准 x0，缓存 x0 和ADMM变量
  -> 三阶段共享的分组先验 + 保留TV的raw近端求解
  -> 六幅postblur滤光图
  -> 同一Radiometry.fit
  -> 有效色温、三个波段总辐亮度、三个有符号超额发光读出

第一版不训练或输出潜在温度、浓度、发射率、任意背景谱；不增加不确定度头；不把估计噪声尺度当神经输出的置信区间。

### 2.1 基准归一化

沿用当前从raw/FFT热通道获得的每帧共享尺度s，以便和现有TV进行公平比较。六幅辐射图使用同一个物理尺度；各通道专用尺度只能作为额外特征或损失尺度，并须保存/可逆。

不要对六幅输入分别做不可逆的逐图零均值、单位方差处理。不要用目标图计算推理尺度。

x已经处于物体光学模糊之后，A=encode_images；不要再次对它调用object_blur。

## 3. 零学习不破坏TV：必须保留的结构

设原TV目标为

J0(x) = 0.5 || W^(1/2)(Ax-y) ||² + sum_c lambda_c TV(x_c) + indicator_support(x).

x0是这个目标的数值收敛解。第一版lambda_c保持与当前TV参考一致，当前选择值0.003；不得只给新方法偷偷使用更好的TV参数。若另扩正则网格，应作为两者共同的新基准选择实验。

每阶段从固定基准提出绝对修正，而不是不受限累积：

z_k = x0 + P_Omega Delta_theta(features(x_k,x0,y,k)).

随后求

x_(k+1) = argmin_x J0(x) + 0.5 || M_k^(1/2)(x-z_k) ||².

M_k为严格正的对角近端强度，按该算子的通道法算子灵敏度缩放；第一版固定各阶段尺度，后续才考虑在小范围内学习。不能把“某个波段很暗”当作无限增大或减小其数据权重的理由。

当神经修正为零，z_k=x0。由于x0最小化J0，且二次近端项也在x0最小，该新问题的解为x0。这个性质是理想收敛算子的恒等性质；实际迭代实现须测量数值误差，不能声称任意有限迭代逐元素完全相等。

非常重要：非零神经修正后，不要求 J0(x_new) <= J0(x0)。x0本来就是原目标的最小点，这种门槛会阻止有意义的修正。应优化包含新先验中心的增广目标，最终效果由独立真值评价，而非训练时或推理时访问真值做接受判断。

### 3.1 复用当前ADMM/PCG实现

当前Imager.normal、precondition已经处理六波段侧带与公共DC耦合，应保留，不换成CASSI的对角闭式公式。

ADMM图像子步变成：

(A^T W A + M_k + rho D^T D) x = A^T W y + M_k z_k + rho D^T(d-u).

梯度收缩仍按每通道空间TV进行。保存TV初始化的d/u状态；每个阶段warm start，不从零ADMM状态重复建立一个不一致的近端解。

初始实施预算：每阶段8–12轮ADMM，每轮6–10次PCG。预算不是正确性的保证，必须通过增加迭代后的输出变化、stationarity与梯度测试确定。不要只报告PCG递归残差。

先实现1阶段的可微接口与测试，再扩到同一架构的3阶段。可使用activation checkpointing。首版明确反传固定迭代过程；不要在未核验前用不匹配的隐式梯度代替。如果平滑TV以实现梯度，则需要重新建立对应平滑TV参考，不把它静默当原TV。

不能写 `if neural_delta == 0: return x0` 来掩盖数值或梯度问题：这可能在零头初始化时切断学习。测试必须同时检查输出接近x0和残差头获得正确的非零梯度。

## 4. 分组可学习先验

### 4.1 热通道支路：联合处理700/800/905，但输出三个可逆辐射坐标

三个NIR图像保留完整三个自由度，不强制落在单温度灰体流形。

定义：

l_i = log(I_i)，
b = (l700+l800+l905)/3，
r1 = l700-l800，r2 = l905-l800。

逆变换：

l700 = b+(2r1-r2)/3；
l800 = b-(r1+r2)/3；
l905 = b+(-r1+2r2)/3。

网络输出Delta_b、Delta_r1、Delta_r2，修正围绕TV基准坐标。使用 b、两个ratio的噪声尺度分别限制修正，而不是六路统一乘0.2。

可采用 Delta_q = 2*sigma_q*tanh(head_q)。sigma_q只由raw噪声模型、固定线性近似和基准图计算，不是校准过的输出置信度；其近似层级必须记录。首版至少利用per-channel噪声和亮度换算；完整协方差留为可验证增强，不能把相关通道直接宣称独立。

在强度域用 I0*expm1(Delta_l) 构造Delta_I，以保证Delta_l=0时数值上Delta_I=0，避免exp(log(I0))-I0的无意义舍入偏差。

NIR输入建议：TV辐射坐标、当前辐射坐标、FFT-TV差、每路噪声尺度、对应侧带残差、阶段编号。只喂NIR组自身的图像，不把三个可见发光图直接混入热支路。

对非正热输入：记录异常，日志用明确数值floor；不能仅靠clip制造有效温度。最终band-support投影可能产生负值，需要把它作为失败/物理形式问题记录；若引入非负约束，应在共同TV基准与新方法中一致实现，不能用最后一次ReLU静默改变带宽。

### 4.2 可见支路：一套共享单通道网络，逐波段独立应用

对431.5、486、516.5各自调用同一套f_V；共享权重节省数据，但中间特征不互相拼接。每个波段输入自己的x0_i、xk_i、FFT-TV差、侧带复残差实/虚部、噪声尺度和本通道空间梯度。可用波长、载频灵敏度、log噪声和stage进行FiLM条件化。

第一版不允许可见1的图像通过先验直接生成可见2；不使用六路全谱注意力或全六通道硬低秩约束。该限制只约束可学习先验，raw求解器仍联合使用所有通道的真实物理耦合。由于输入自身及raw求解存在噪声耦合，这不是“串扰数学上恒为零”的保证。

输出 Delta_i = 3*sigma_i*tanh(h_i)，再投影到共同光学支持。它是有符号加法修正，可纠正TV弱信号收缩；不对超额发光套ReLU，不用只保持原符号的乘法门限制可恢复性。

### 4.3 先验骨干只选一个

两套轻量三尺度NAF式U形骨干：一套NIR，一套由三个可见通道共享。

- 128x128: width24、2个NAFBlock；
- 64x64: width48、2个NAFBlock；
- 32x32: width96、4个NAFBlock；
- decoder64/128: 各2个块、跳跃连接、可学习上采样；
- 输出头零初始化；3阶段共享先验权重；
- first version参数预算不超过约1M，实际实现统计，不承诺未经计算的参数数。

不对输入辐射图做BatchNorm；内部特征归一化可以使用带skip的LayerNorm。保持当前周期边界约定完成首轮，非周期实光学测试作为独立域变化，不静默换padding。

NAFNet提供的是简洁多尺度图像恢复骨干，不是此测温任务的现成答案。MoDL/DAUHST提供物理步骤与先验展开的参考，不可直接借用CASSI特定法算子。LRDUN的低秩光谱机制也不能直接当作三个独立发光通道的约束。

## 5. 物理读出与损失：不让网络替读出模型背锅

保持当前统一R_T(X)、R_E(X)，不新增一个直接输出T或species的自由头。

### 5.1 主通道监督

L_channel使用六幅真值通道图的稳健绝对尺度/相对误差；尺度来自预先固定训练统计或明示的强度组。保留均值偏差损失，避免去噪整体拉低强度。

### 5.2 温度监督

对最终三幅NIR图执行可微、已验证的同一辐射拟合，监督 (R_T(Xhat)-R_T(Xtruth))/50 K，同时保留两个log-ratio误差作为稳定项。

这里的50 K是损失量纲和已有开发目标，不是精度保证。监督真值是对无噪postblur三波段做同一拟合得到的有效色温，不是latent温度。

独立局部计算：在3000 K、800nm=4000e的均匀输入，dT/dlog(I700,I800,I905)约为[1690.24,599.35,-2289.59] K。共同1%乘法误差一阶几乎不改变色温；700增加1%、905降低1%约产生39.80K。公式来自本分支Radiometry，非已训练模型评估。

### 5.3 发光读出监督

用 L_readout = ||R_E(Xhat)-R_E(Xtruth)||² / s_E²，而不是把实际注入量直接当成唯一神经读出目标。

因为 R_E(Xtruth)=E_injected + b_mixing，b_mixing来自模糊/曝光混合后的连续谱不能被一个单温度灰体完全外推。强迫R_E(Xhat)=E_injected可能逼网络改变原本正确的NIR图或可见图来补偿读出假设。

评价时必须保留两列：恢复后读出相对无噪读出的误差、恢复后读出相对实际注入的总误差。用二者区分图像算法误差与读出模型偏差。

### 5.4 配对单波段注入损失（必须实现）

同一母场景的blank和第j波段注入构成训练对：

Delta_Xhat_j = f(y_j)-f(y_blank)，
Delta_Xtruth_j = Xtruth_j-Xtruth_blank。

监督六路Delta差；同时监督Delta_R_E。目标通道应保留注入幅值，未注入通道及热通道不应出现系统性增量。此处只在训练/评价成对，部署每次仍只输入一张raw。

Poisson均值随注入变化，不能说相同seed意味着同一加性噪声。使用多个独立噪声重复，或明确验证过的方差降低耦合；不要从输入相减生成部署额外信息。

不要把含噪null的每个像素直接强制为0。只约束相对真值/无噪读出的误差和配对响应，并用独立null数据标定检测。

建议总损失由无量纲L_channel + L_T + L_readout + L_pair + 0.5L_mean组成；各尺度先固定。阶段性训练时打开对应部分。第一轮不大范围搜索loss权重，不添加感知/GAN损失。

## 6. 数据与训练安排

当前24个训练母场景和300次更新只是小试验。当前300*batch4/576约2.08次训练帧等效暴露，不能据此证明该任务或整个混合范式已达到极限。

第一轮推荐：256个训练母场景，32验证，32阈值标定，64新留出。每个维持两光子水平、六注入条件、两次独立噪声；可根据算力先用固定64/16开发子集验证实现，但正式比较不能在旧8个已暴露留出母体上选模型。

温度、幅度和三路发光形态使用独立随机流；加入随机方向前沿、多热点、环/条、细丝、平坦场。每个母场景内所有注入与噪声重复不跨split。对场景做增强后重新光学编码；不直接旋转raw但沿用旧载频。

所有训练raw只求一次匹配的TV缓存；保存s、W、xTV和ADMM变量。重新抽噪声必须配新TV缓存。

训练从新网络的零输出头开始，不载入当前约83K的失败检查点。

建议单种子起始：AdamW lr=2e-4，weight_decay=1e-4，grad_clip=1，有效batch4（配对损失每对两帧，实际显存按pair计）。三段共6000次实际更新：

- 1500步：先训练NIR支路；可见神经头关闭，建立温度/比例收益；
- 1500步：冻结NIR先验参数，训练可见支路与配对响应；
- 3000步：整套三阶段联合小学习率5e-5微调，所有读出和通道约束保留。

这是起始设计而非足够训练的证明。每100–200步固定验证，保存最佳验证候选和末次。若参数曲线尚未平台、应完整记录未收敛，不能仅因有限预算未胜TV便宣布理论极限。形成同权重明确收益后再补另外两个种子，不选择“最好种子”冒充稳定性能。

## 7. 必须有的四组方法对照

A. 原收敛WTV（若共同更新TV设定，则新旧两版都报）。
B. TV初值 + 容量相近的普通六通道残差多尺度网络，无TV近端。
C. TV初值 + 本设计分组先验，无TV近端。
D. 完整分组先验 + 保留TV的近端展开。

对D额外做一次去掉配对注入loss的控制，以核对串扰改进的来源。数据、尺度、训练预算、选择集尽量相同；不同方法独立训练。不要把post与DC复用同一个训练权重来作正式因果比较。

## 8. 软件和科学验收

软件：
- zero neural heads => 输出接近xTV；同时活跃输出头梯度非零，不能用分支返回绕过求解；
- 三NIR坐标正反变换一致；保留3个自由度；
- 可见先验模块中修改另一可见组输入不改变本组proposal（不包括上游/后续物理耦合）；
- forward/adjoint/preconditioner仍使用当前6载频；没有额外object_blur；
- 近端前后结果保留共同支持；记录非正热像素，不能clip后藏失败；
- ADMM/PCG固定迭代反传在小尺寸和代表native输入做有限差分，零修正点也要验证；
- 神经关闭控制与TV基准读取同raw、同W、同lambda、同归一化。

科学：
- 六路图像、去均值细节、均值偏差分别报告；
- 色温RMSE与NIR对数比偏差；
- 三路发光相对clean_readout和actual_injection的两种误差；
- blank及“其他波段注入但本波段未注入”的误报；
- 完整3x3注入响应矩阵，不能只看对角目标通道；
- 继续采用幅值斜率0.90–1.10为开发目标，off-diagonal response可预登记绝对值<=0.05的初始目标，阈值并非既有性能；
- 相对新留出上的TV，每路弱发光RMSE争取至少降低15%，温度与细节不明显退化；原50K/5%仍单列，不把相对改善冒充绝对达标；
- 每个光子水平、每种seed、每个母场景成组bootstrap；像素和噪声副本不当独立物理样本；
- 真实设备速度包含TV初始化及全部近端步骤，不能将已缓存TV后的CNN耗时称在线总时延。

本方案不保证所有指标同时通过。它的明确假设是：强传统解作为固定点、任务分组先验和保留TV的近端比“FFT初始化+全谱浅CNN+纯WLS近端”更符合当前误差机制。该假设应由上述同输入对照验证。
