# 六通道测温与特征发光联合成像小试验

本阶段把单视场、同一传感器区域重叠编码得到的一幅原始图，恢复为六幅滤光通道图像，再输出连续谱色温和三个特征波段的发光分布。用户于2026-10-17明确应用为燃料燃烧、爆炸等超快相机场景，确认首轮关注CH*、C₂*和AlO，并要求以先进传统算法与神经网络融合推进研究。

| 用途 | 仿真中心波长 | 读出量 |
|---|---|---|
| 连续谱测温 | 700、800、905 nm | 三通道积分光子Planck曲线与灰体幅度拟合得到的有效色温 |
| CH*相关发光 | 431.5 nm | 总通道图像；另报告相对于拟合连续谱的波段超额发光 |
| AlO相关发光 | 486 nm | 同上 |
| C₂*相关发光 | 516.5 nm | 同上 |

各通道暂用10 nm理想矩形响应。测温窗口是待验证设计点；真实滤片、量子效率、分光损耗和场景光谱会决定最终选择。三个特征通道的中心有实验光谱依据，通道亮度还包含连续谱和其他发光体。当前工程对照使用三个独立的正发光图分别注入可见波段，评价的是通道发光检出能力。化学物种的唯一识别需要实测交叉响应与具体场景证据。

温度首先定义为曝光、视线和光学响应共同积分后得到的连续谱有效色温。灰体假设与单温度近似成立时，它可以对应主要辐射颗粒/液滴的温度。Yu等的双范围发射光谱实验分别测得液相连续谱温度和AlO光谱温度，二者具有不同来源及空间演化。[原始作者稿](https://alternativefuelslaboratory.ca/wp-content/uploads/2024/07/2024-Yu-Dual-range-emission-spectroscopy-for-temperature-measurement-of-laminar-aluminum.pdf)

这里先对各通道辐亮度进行光学模糊，再拟合无噪声参考色温；温度场本身不作为可线性模糊的图像。解析对照还单独检查曝光内双温度混合、发射率斜率和特征波段交叉响应。

## 算法与对照

所有方法使用同一张原始ADC图及固定标定，输出同一光学频带内的六幅图。空间编码复用及其分辨率代价沿用已有思想；新六载频布局用整数频点实现，正负载频和直流窗口的最小间距为0.270858 cycles/pixel，大于两个0.13解调窗口半径之和。目标图像的截止频率为0.12 cycles/pixel。与此前三通道0.13截止频率的开发试验相比，本次通道数、网格大小和场景均有变化，应使用本轮内部对照评价。

1. **频域基线**：锁相解调后投影到共同光学支持。
2. **噪声加权传统基线**：固定估计散粒/读出/量化噪声方差，在原始图域求解加权最小二乘与各通道空间TV正则。ADMM子问题使用矩阵自由共轭梯度；预条件器利用本编码几何下“各通道侧带对角项＋共有直流项”的频域结构。三档正则强度仅在验证母场景选型，并用加倍迭代检查数值变化。
3. **CNN后处理**：三阶段共享的小型残差网络，输入当前通道估计、频域初值和从同一raw估计的噪声尺度。
4. **混合重建**：相同网络容量、数据、损失和训练次数；每阶段神经先验之后，解带先验近端项的原始测量一致性子问题。它与CNN后处理分别从头训练，各保留三个随机种子。

另保留充分求解的噪声加权无正则最小二乘，以及关闭网络、保留相同三次物理近端步骤的对照，以区分网络学习和额外数值求解的收益。传统参考在频域、加权最小二乘和TV候选中按验证通道误差选定。

两类网络都用通道相对误差、平均强度误差与测温通道对数比值误差训练。温度和特征发光读出在图像恢复之后计算；推理不输入真值、潜在温度或生成场景参数。数据一致性不等于物理量正确，最终按温度、弱发光幅值、空白误报和图像细节共同评价。

## 文献与创新假设

- Andersson等2024已实现被动分光、空间载频复用、单相机重叠采集和测温；2026工作进一步用于铝燃烧高速温度成像。这一光学框架属于既有技术。[2024论文](https://www.nature.com/articles/s41598-024-66386-2)；[2026论文](https://doi.org/10.1364/OE.578636)。本轮重读本地保存的2024出版社全文；2026的当前核验层级为出版社书目信息和作者摘要。
- DAUHST将观测与物理掩模中的退化信息用于控制展开迭代；LRDUN进一步把光谱低秩结构写入成像模型并交替展开谱基与子空间图像。[DAUHST，NeurIPS 2022](https://arxiv.org/abs/2205.10102)；[LRDUN，CVPR 2026作者全文](https://arxiv.org/html/2511.18513v2)。本轮已读LRDUN成像及展开方法正文；其CASSI光谱低秩假设不能直接证明独立化学发光通道的保真。
- OH*、CH*、C₂*分别使用310、431.5、516.5 nm、10 nm带宽滤片的实验给出波段依据。[Abu Saleh等2024原文](https://eprints.whiterose.ac.uk/208382/1/ffuel-01-1296502.pdf)。Lucas等的含铝发光光谱支持486 nm附近AlO波段，同时提示AlO与C₂发光区域重叠。[原始论文](https://doi.org/10.1021/acs.jpca.9b10697)。

本轮检验的具体假设是：结合实际空间编码算子的噪声加权数据步骤与可学习先验，能否在保留测温通道比例的同时降低弱特征波段误差。先进展开框架、普通CNN和传统优化本身已有先例。若严格对照显示收益，后续贡献再聚焦双用途通道的定量保真机制、误报控制和跨标定验证。

## 预登记评价

共44个独立合成母场景：训练24、验证6、阈值标定6、留出评价8。每个母场景包括两档光子水平、空白/三类单独弱注入/共同弱注入/共同强注入六条件、两次独立噪声重复，总计1056幅raw。噪声副本保持在同一母场景划分内。留出场景在传统参数、网络检查点和全部检测阈值冻结后才进入评价。

主条件为800 nm通道平均4000电子、每个可见特征注入平均200电子。继续线为：各通道平均相对L2不超过5%、有效色温RMSE不超过50 K；相对于选定传统方法，三个弱发光通道的全像素合并RMSE各降低至少15%，温度、各通道图像及去均值细节误差恶化不超过5%；强度偏差不超过2%，独立空白误报率各不超过2%，配对弱注入响应斜率在0.90–1.10。每个神经随机种子都需通过。上述数值是项目小试验筛查线。

阈值使用空白标定帧中“超额发光/从raw估计的上游噪声尺度”的99分位数，评价时报告两个光子水平各自的误报率。该尺度用于构造检测统计量，不作为神经输出的置信区间。噪声加权项是固定方差的高斯近似，数据包含真实Poisson抽样、读出噪声和量化；当前方法不等同于精确Poisson-Gaussian极大似然。

完整参数见protocol.json，源码哈希和资源在REGISTRATION.json。本地只执行秒级CPU算子/导数/辐射控制；服务器执行全部数据生成与六次训练，每次300次更新。每个运行使用独立目录，保存原始ADC、目标、源码、检查点、指标和失败结果。当前结果属于物理假设明确的合成小试验，实测曝光、帧率和气体温度均待相应证据。
