# 滤波通道图像解码

滤光片定义通道波长，算法恢复各通道完整的透过滤片图像。波长在本试验中是已知通道标签，不是待估参数。目标图像包含通带内的全部发光。三路共用一个视场，在同一传感器区域重叠编码。

前向模型为 `y = H_relay(sum_k P_k x_k) + noise`。`x_k` 是经过指定物镜空间传递函数之后、空间编码之前的通道图像。解码利用不同空间载频分离图像，再补偿登记的中继光学传递函数。没有温度、化学模板、浓度或跨通道谱形约束，没有神经网络训练。

当前试验通道为 431.5、486、516.5 nm，初始带宽均按约 10 nm 规划。OH* 附近 310 nm 是待核对紫外光学/传感器响应的扩展。波段依据和未知硬件参数见 `protocol.json`；实际滤片尚未据此采购或标定。

三个冻结开发试验为：

| 运行 | 物镜截止频率，cycles/pixel | 用途 |
|---|---:|---|
| filter_decode_001 | 0.075 | 复用既有空间算子的窄带基线 |
| filter_decode_002 | 0.16 | 扩大带宽的对照，未通过全部细节误差门槛 |
| filter_decode_003 | 0.13 | 近似等半径载频的中间方案，通过均衡亮度下的工程门槛 |

当前基线及完整评价见 `../reports/filter_decode_003/RUN_REVIEW.json` 与 `RESULTS_zh.md`。第三组并未通过所有亮度比条件：20倍暗弱通道仍有约30%的相对图像误差。第一组更平滑、噪声更低；应按需要的空间细节和光子数选择工作条件。

每组固定8个母场景、3档电子数、4种亮度比、8次噪声重复，共768帧含噪观测。三个通道的形态来自同一母场景随机数流的不同抽样段，没有谱参数绑定。各组复用母场景形态，属于开发对照。源码中的 `images` 给出完整生成过程；种子措辞澄清见第三组的 `METADATA_CLARIFICATIONS.json`。

原始ADC帧、图像真值、失败结果、逐帧指标、调用账本和哈希均保留在对应报告目录及服务器同名目录。`source.tar.gz` 是每次运行的独立可复现源包；本地包位于 `outputs/filter_decode_transfer/`。三组均保留完整 `source_snapshot`，其中包含逐字节冻结的运行源文件和登记哈希。Git属性为本研究目录保留原始换行，以免跨系统检出改变登记哈希。

复现时在服务器上新建独立目录，解包对应源包，设置 `THERMOMETRY_RUNTIME` 到该目录，运行 `python3 -B -m research_filter_decode.supervise`。监督程序保留真实退出码并限制运行时间；使用新目录可保留原始结果。第三组使用服务器CPU的两条线程，其余两组使用CUDA。查看登记配置前不得把这些合成电子数换算成相机帧率或实测精度。

下一步保留同一目标空间带宽，比较当前解调与利用raw噪声方差的独立三通道图像重建，重点检查暗弱通道误差、细节和偏差。真实硬件应用还需要滤片响应、载频/相位/增益和光学PSF标定。
